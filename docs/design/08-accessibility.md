## Accessibility

Accessibility is part of the design foundation rather than a later visual adjustment.

Implementation should preserve the following principles established during design:

- sufficient foreground/background contrast;
- visible keyboard focus;
- semantic heading hierarchy;
- keyboard-accessible navigation and controls;
- clear link and button affordances;
- accessible names for icon-only controls;
- readable long-form text;
- no information communicated exclusively through color;
- support for `prefers-reduced-motion`;
- sufficiently large interactive targets;
- semantic anchor-based project navigation.

The final implementation palette must be validated against WCAG contrast requirements during Stage 2.
