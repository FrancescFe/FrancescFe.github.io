## Design direction

The portfolio follows a **minimal, technical, developer-oriented visual language**.

The interface deliberately borrows subtle conventions from development environments — such as monospace typography, editor-like navigation, terminal-inspired details, technical labels, and structured metadata — without attempting to reproduce an IDE literally.

The intended result is:

- sober rather than decorative;
- technical without becoming gimmicky;
- highly readable;
- content-first;
- visually consistent with a software engineering portfolio.

Decorative elements should support this identity but should not compete with project content or professional information.
