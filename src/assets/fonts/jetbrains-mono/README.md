# JetBrains Mono

The local webfont files are the Regular (400), Medium (500), Bold (700), and ExtraBold (800) static `woff2` assets from the official [JetBrains Mono v2.304 release](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304).

JetBrains Mono is distributed under the SIL Open Font License 1.1 included in `OFL.txt`.
